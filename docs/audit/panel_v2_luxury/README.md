Система «Obsidian & Champagne» снята дословно с прототипа, который одобрил владелец (`docs/audit/luxury_dashboard_prototype/index.html` == `/config/www/lux-dashboard.html`): токены `--bg #070706 / --ivory #f7efe0 / --muted #b9ad9a / --gold #d8ae68 / --gold2 #8c6737 / --emerald #67d99a / --line rgba(222,180,108,.24)`, фон страницы `#050505`, единая кривая `cubic-bezier(.2,.8,.2,1)`, рецепт карточки (`border 1px золотой волосок, radius 20, linear-gradient(145deg,…), inset 0 1px rgba(255,255,255,.045), 0 18px 45px rgba(0,0,0,.3), backdrop-filter blur(18)`), атмосфера (дрейф тёплого свечения 22 s + две тонкие диагональные полосы света в `mix-blend-mode:screen`), гало-дуга героя (9 s) и тихое статичное гало карточек комнат, плавающий док `min(760px,94%) × 66px, radius 26, blur(22)`.

**Отступление ровно одно, и оно намеренное:** прототип строит подписи по лестнице 10/11/12/13/14/16 px. Панель висит на стене и читается с ~3 м, а требование проверки — «нет текста мельче 14 px». Поэтому санс-лестница поднята до 14/15/16/18/20/22 px, включая надстрочники (10 px → 14 px, трекинг +0.20em и золото сохранены). Сериф-лестница (20/22/24/26/30/32/34/40/42/46 px, **всегда вес 400**), отрицательный трекинг дисплейных цифр (−0.03…−0.045em), контраст трекинга и вся геометрия — без изменений. Межстрочный интервал сериф-цифр поднят с 1.0 до 1.1: у Georgia глиф выше em на ~6 %, и `line-height:1` реально обрезал числа на 2–3 px.

Эмодзи в панели нет ни одного — включая имена сценариев из Home Assistant, которые чистятся `cleanName()` перед показом.

## 10. Что НЕ проверено и что осталось за кадром

* Панель не открывалась на самом планшете SM-T595 — вся проверка headless (Chromium 151). Реальные метрики шрифтов на устройстве могут отличаться на доли пикселя; запас по помещаемости на «Дом» при 1280×800 — весь ряд нагрузок ровно 44 px, это самое узкое место.
* Ни одна команда не отправлялась в дом: физическое подтверждение контракта «отправил → перечитал → сказал правду» на живом устройстве не выполнялось.
* Тема выбиралась вручную (`themeMode`); автоматический переход по освещённости/солнцу/часам с выдержкой 120 s на живых данных не наблюдался — механизм перенесён из предыдущей сборки без изменений и покрыт `tests/test_panel_v2_build_marker.py`.
* `panel_custom.module_url` в `/config/configuration.yaml` остался с `?v=20260816-v2-1`. Файл конфигурации не трогался; обновление доставляет собственный поллер панели. При ближайшем перезапуске HA владельцем `?v=` стоит поднять до текущей сборки.
* Серверная/Proxmox-диагностика (гости, хранилища, обновления HA) в v2 пока не выведена нигде — в классической панели это была вкладка «Сервер». Это осознанный пробел, а не потеря: содержимое диагностическое, не управляющее.

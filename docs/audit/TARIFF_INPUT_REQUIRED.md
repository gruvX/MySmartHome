# Тариф — какие числа нужны от владельца

**Автор:** tariff-model-agent · **Дата:** 2026-07-16 · **Только чтение, ничего не задано и не развёрнуто.**

Система сейчас показывает **только рыночную часть** цены (Nord Pool spot). Чтобы она
считала реальный счёт за электричество, нужно один раз переписать несколько чисел из
**договора с поставщиком** и **последнего счёта** (Elektrum / Tet / Sadales tīkls и т. п.).

**Пока хоть одно число ниже пусто — система НЕ показывает «Итоговый счёт».**
Она показывает только `Стоимость Nord Pool` (spot). Это честный дефолт: никаких выдуманных
ставок. Все значения по умолчанию — `null`, НЕ `0`.

Единицы важны: почти всё — **EUR за кВт·ч** (EUR/kWh), НЕ центы и НЕ EUR/МВт·ч.
Все ставки вписывать **без НДС** (PVN отдельной строкой, слой 3).

Заполнять **только** если у вас двухзонный распределительный тариф. Иначе оставить пустым и
использовать одну ставку `distribution_eur_per_kwh` (строка 2).

## Пять слоёв счёта (как всё складывается)

1. **Nord Pool spot** — биржевая цена, EUR/kWh, за каждый 15-мин интервал. Берётся **вживую**
   из `sensor.nord_pool_lv_current_price`. Не хранится и не вводится.
2. **Переменные надбавки** (EUR/kWh) — строки 1–4 выше: наценка + распределение + передача + налог.
3. **PVN / НДС** (%) — строка 6.
4. **Фиксированная плата** (EUR/мес) — строка 5.
5. **Полный расчётный счёт** = собирается из 1–4.

Формула (когда все поля заданы):

```
spot        = kWh × цена_Nord_Pool(интервал)                     # слой 1
addon       = kWh × (наценка + распределение + передача + налог)  # слой 2
energy_sub  = Σ(spot + addon)  по всем интервалам периода
vat         = (energy_sub + fixed_monthly_eur) × vat_percent/100  # слой 3
ИТОГ        = energy_sub + fixed_monthly_eur + vat                # слои 4 + 5
```

**Пока любое из полей 1–6 пусто:** `ИТОГ = null`, а на экране — `Стоимость Nord Pool`
(только слой 1). Никогда не «Итоговый счёт».

---

## Куда это идёт

Числа вписываются в машиночитаемую схему:
`docs/audit/tariff_schema.json` (сейчас все значения `null` + единицы + даты действия).
Владелец заполняет — агент по расчёту стоимости после этого сможет показывать полный счёт.
Ничего в дом/HA этим документом не меняется.

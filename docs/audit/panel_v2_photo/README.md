## 1. Как собран герой

Один блок высотой **188 px** при 1280x800, четыре слоя, все обрезаны его радиусом 24 px,
поэтому картинка доходит до всех четырёх краёв — композиция A1:

| слой | что делает |
|---|---|
| `.hero-bg` | сам PNG, `background-size:cover`, `background-position` подобран по кадру |
| `.hero-grade` | цветовая заливка тира (`mix-blend-mode`) — именно она делает «день» и «вечер» одной комнатой при разном свете |
| `.hero-scrim` | **слой контраста**. Его стопы выбраны замером реально скомпонованных пикселей, а не на глаз |
| `.hero-l` / `.hero-r` | слова, `z-index:1`, на тёмной стороне кадра |

Оба файла — 1891x831 (2.28:1) и оба уже темны слева: у вечерней комнаты левые ~40 % —
неосвещённая стена, у виллы левые ~55 % — ночное небо. Кадр героя 6.5:1, поэтому `cover`
масштабирует файл по ШИРИНЕ и показывает средний вертикальный поясок — а это лучшая часть
обоих файлов. Отсюда и лёгкий скрим: картинкам почти не нужна помощь, а утопить их было бы
ровно тем, ради отказа от чего они и добавлены.

Слева сверху вниз: дата-надбровие → **приветствие по часам** → состояние дома → подсказка.
Справа — две «стеклянные» плашки (цена и текущая мощность): они стоят на СВЕТЛОЙ стороне
кадра, и без собственной подложки «Дом потребляет» мерялось 2.1:1 над свечением лампы.

Герой закрепляет **свой** набор токенов (светлый текст на тёмном) во всех трёх тирах,
включая «день», где палитра страницы — тёмные чернила на пергаменте. Фотография тёмной
комнаты не может нести тёмный текст на 4.5:1 без почти непрозрачной белой заливки, которая
выбросила бы картинку; локально тёмная плашка сохраняет и картинку, и замер. Это
осознанное задокументированное отступление. Правило честности не тронуто: цвет по-прежнему
даёт только `[data-kind="real"][data-tone=…]`.

Приветствие — факт, которым панель владеет (часы), поэтому это обычный `Val`. Проверено по
часам: 00:30/04:30 «Спокойной ночи», 05:30–11:30 «Доброе утро», 12:30–17:30 «Добрый день»,
18:30–22:30 «Добрый вечер», 23:30 «Спокойной ночи» — всё «…, Владелец».

## 2. Три тира

| тир | файл | грейдинг | честная оценка |
|---|---|---|---|
| **вечер** | `home-hero-evening.png` | `saturate(1.1) contrast(1.05) brightness(1.06)` + тёплая заливка `soft-light` | лучший из трёх: тёплая лампа, город за стеклом, диван читается |
| **день** | тот же файл | `saturate(.45) contrast(.85) brightness(2) hue-rotate(-12deg)` + холодная заливка `screen` .34 | **честно: это ночной рендер, поднятый по яркости в 2 раза.** Читается как прохладное пасмурное утро в той же комнате — но лампа в кадре всё ещё горит, а за стеклом всё ещё ночной город. Это не «дневная фотография», это холодный high-key грейд ночной. Я перебрал четыре варианта (см. ниже) и этот — единственный, который не выглядит ни как выцветший туман, ни как всё тот же вечер. Он не дешёвый, но он и не честный «день»; настоящий день потребовал бы третьего рендера, а плодить ассеты задание запрещает |
| **ночь** | `home-hero-orbital.png` | `saturate(1.06) contrast(1.08) brightness(1.04)`, кадр `50% 66%` + холодная синяя заливка | вилла со светящимся интерьером, огни террасы, береговая линия и дуга планеты сверху |

Перебор для «дня» (b = brightness, s = saturation): b1.62/s.62 читался всё ещё вечером;
b2.3/s.30 — выцветший туман; b1.85/s.55 — снова вечер; выбран **b2.0/s.45 + холодная
заливка .34**. Ни один файл не перекодирован и не добавлен: на них ссылаются ещё
`tablet-panel.js`, `tablet-panel.luxury.js`, `tablet_command.html` и `smarthouse_v8.html`.

## 4. Контраст над фотографией — измерено по скомпонованным пикселям

Метод: для каждого текстового узла берутся точные `Range.getClientRects()`; затем страница
снимается ВТОРОЙ раз с `color:transparent` на всём тексте, чтобы получить чистый фон; затем
для каждого прямоугольника сэмплируется сетка реальных пикселей этого фона и считается
худшее WCAG-отношение к вычисленному цвету текста. Порог — **4.5:1 для ВСЕХ узлов**,
без поблажки для крупного текста.

| охват | замеров | провалов | худшее |
|---|---|---|---|
| «Дом», 3 тира x 3 размера | 9 x ~81 текстовых прогонов | **0** | **5.01** (`Всё управление` в верхней строке, день — не над фото) |
| только узлы героя (над фотографией) | 9 x 10 | **0** | **6.53** (`дорого до 23:45 (конец цен)`, день, 1280x800) |
| все остальные экраны/страницы/линзы, 3 тира x 3 размера | 261 вид | **0** | **4.87** (`auto_p1`, день, 1366x768) |

**Глобально худшее по всей панели: 4.87:1.** Над фотографией минимум 6.53:1.

Замер нашёл настоящий дефект, который глаз пропустил: золотой маркер активного пункта дока
попадал внутрь строчного бокса подписи на 768-высоких экранах, и «Дом» мерялось **1.74:1**.
Исправлено (`.navb{padding:0 0 7px}`, маркер `bottom:2px`, ослаблено свечение).
